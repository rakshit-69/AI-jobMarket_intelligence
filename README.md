📊 AI Job Market Intelligence 2026

Skills, Salaries & Career Trends

A data analysis project exploring AI job demand, salaries, job categories, countries, and in-demand skills using a Kaggle dataset.

🔍 Key Insights
🇮🇳 India: 83.5% AI-related postings
💼 Top categories: IT & Engineering
🧠 Top skills: AI, Machine Learning, Data Science, Generative AI & Python
💰 AI roles show higher median salaries than non-AI roles in the analyzed UK and US data.
🛠️ Tech Stack

Python • Pandas • NumPy • SQL
